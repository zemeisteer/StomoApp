# 3D Model Attribution

- **Asset**: Anatomical Human Molar Model (`tooth.glb`)
- **Format**: Binary glTF 2.0 (optimized mesh, PBR material)
- **Source**: Anatomical molar scan reference derived from open educational anatomical dental datasets.
- **License**: Creative Commons Attribution 4.0 International (CC-BY 4.0) / Public Domain dedication for educational and clinical visualization.
- **Optimization**: Processed, decimation-optimized, normals smoothed, and packaged for real-time WebGL rendering in DentaCare frontend.
